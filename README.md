# My_First_Conditional_Statement
A Python logic script using conditional branching (if-elif-else) to determine school eligibility based on user-provided age data.

# Kindergarten Age Checker

## What it does
This program asks for a child's age and tells you if they are ready for kindergarten. It uses **Conditional Logic** to make decisions based on the number entered.

## Features
* **Input:** Takes a number (age) from the user.
* **Logic:** * Under 5: Not old enough.
  *Exactly 5: Perfect age.
  *Over 5: Too old.

## How to use
1. Run the script: `python "My First Conditional Statment.py"`
2. Type in an age when prompted.
3. See the result!

## Why I built this
To practice using `if`, `elif`, and `else` statements in Python
